# Koldrop email templates

Paste each file into Supabase → Authentication → Emails → Templates (Source / HTML view).
Links go to `https://koldrop.vercel.app/auth/confirm`, which verifies the token (app/auth/confirm).

| Supabase template | File | Subject |
|---|---|---|
| Confirm signup | confirm-signup.html | Confirm your Koldrop account |
| Reset password | reset-password.html | Reset your Koldrop password |
| Change email address | change-email.html | Confirm your new Koldrop email |
| Magic link | magic-link.html | Your Koldrop sign-in link |
